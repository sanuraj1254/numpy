# NumPy Practice 🧮

A hands-on repository documenting my journey of learning NumPy, a fundamental Python library for numerical computing.

I'm a BTech Artificial Intelligence & Data Science student building strong programming foundations for Data Science, Machine Learning, and AI Engineering.

## 📚 Topics Covered

- NumPy array creation and initialization
- Array indexing and slicing
- Array reshaping and manipulation
- Mathematical and statistical operations
- Aggregation using `sum()`, `mean()`, and `average()`
- Working with rows, columns, and axes
- Vector operations and linear algebra basics

## 🚀 Projects

### 1. Vector & Matrix Calculator

A Python calculator built using NumPy to perform basic vector and matrix operations.

**Vector Operations**

- Vector Length
- Dot Product
- Angle Between Vectors

**Matrix Operations**

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose

**Concepts Used**

- NumPy arrays
- Functions and user input
- Conditional statements
- Loops and nested loops
- NumPy linear algebra operations
- Matrix dimensions and shape checking

**Run the calculator:**

```bash
python "Projects/Vector_&_Matrix_Calculator.py"
```

**File:** [`Vector_&_Matrix_Calculator.py`](Projects/Vector_&_Matrix_Calculator.py)

### 2. Weather App 🌦️

A Python terminal application that fetches current weather information using the Open-Meteo API.

**Features**

- Search for a city in India
- Fetch current weather information
- Display temperature, relative humidity, and wind speed
- Handle invalid city names
- Handle API request errors

**Concepts Used**

- Python functions and user input
- Working with APIs
- Sending HTTP requests
- Processing JSON responses
- Exception handling

**Run the Weather App:**

```bash
pip install requests
python "Projects/Weather_app.py"
```

**File:** [`Weather_app.py`](Projects/Weather_app.py)

## ▶️ How to Run

**For the Vector & Matrix Calculator:**

1. Clone or download this repository.
2. Open the repository folder in VS Code or a terminal.
3. Install NumPy if it is not already installed.
4. Run the following command:

```bash
python "Projects/Vector_&_Matrix_Calculator.py"
```

**For the Weather App:**

1. Make sure you have an internet connection.
2. Install the required library using `pip install requests`.
3. Run the following command:

```bash
python "Projects/Weather_app.py"
```

**For the notebooks:**

1. Open the repository in Jupyter Notebook or JupyterLab.
2. Open any `phase-*.ipynb` notebook.
3. Run the cells in order.
